# GTD Book Writing Manual

The user manual for the GTD Book Writing plugin — written *with* the plugin. Every chapter here is a scene with a real pipeline status; if you're reading a compiled copy, it was produced by the plugin's own Compile command.

## Structure

- **01 Getting started** — install, first book, the panel *(sequential: read in order)*
- **02 The GTD core** — statuses, next actions, available/stalled
- **03 Writing in a scene** — the scene card and beats
- **04 Staying on track** — forecast, pacing, weekly review
- **05 Compiling** — from scenes to a single manuscript
